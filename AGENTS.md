# Documentation Workflow

For changes within this repository:

- Work in the current workspace; do not create a Git worktree unless the user
  explicitly asks for one.
- Use inline execution for every implementation task; do not use or offer
  subagent-driven execution.
- Do not create a design spec or implementation plan unless the user
  explicitly asks for one.
- Make the requested documentation change directly, then run focused
  verification appropriate to the change.
