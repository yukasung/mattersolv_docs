# Reports

โมดูลรายงานรวม dashboard และรายงานของทุกโมดูลไว้ที่เดียว
เพื่อให้ทีมและผู้บริหารเห็นสถานะงาน ภาระงาน และผลตอบแทนได้จากข้อมูลชุดเดียวกับ
ที่ใช้ทำงานประจำวัน

ผู้ใช้หลักคือผู้บริหารหรือหุ้นส่วน ผู้จัดการคดี และทีมการเงิน

## Key Capabilities

### รายงานตามโมดูล

- รายงานภาพรวมคดี — คดีที่อยู่ระหว่างดำเนินการ ปิดแล้ว หรือล่าช้า
- รายงานบริการด้านกฎหมาย
- รายงานลูกความ — ลูกความที่มีคดีมากที่สุดและการใช้บริการซ้ำ
- รายงานทนายความ
- รายงานงานและงานค้าง
- รายงานการนัดหมาย
- รายงานเวลาทำงาน — สรุปรายวัน รายสัปดาห์ รายเดือน และเวลาที่ใช้กับแต่ละคดี
- รายงานใบเสนอราคา — อัตราการอนุมัติและปฏิเสธ
- รายงานรายได้และการเงิน

### ขอบเขตข้อมูลที่เห็น

รายงานแยกขอบเขตข้อมูลออกเป็นสามระดับ เพื่อให้ผู้ใช้เห็นเฉพาะส่วนที่รับผิดชอบ

- ของตนเอง
- ของทีม
- ของลูกทีม

ขอบเขตที่ผู้ใช้แต่ละคนเห็นจริงขึ้นกับ role และแผนการใช้งานขององค์กร
ดูที่ [Permissions](/docs/roles/permissions) และ
[Feature Comparison](/docs/plans/feature-comparison)

### Dashboard และการส่งออก

- Dashboard สรุปภาพรวมสำนักงาน รายได้ งาน นัดหมาย และสถานะคดี
- ส่งออกรายงานเป็น Excel, PDF หรือ CSV
