# Finance

โมดูลการเงินรับข้อมูลรายรับและรายจ่ายที่เกิดจากงานกฎหมายมาลงบัญชี
และเตรียมข้อมูลสำหรับรายงานการเงินของสำนักงาน

รอบการพัฒนาปัจจุบันทำเฉพาะ **Finance Foundation** คือวางโครงข้อมูลตั้งต้น
ให้ต่อยอดได้

ผู้ใช้หลักคือทีมบัญชีและการเงิน และผู้บริหารที่ดูผลประกอบการ

## Finance Foundation

สิ่งที่วางไว้ในรอบนี้เพื่อให้ข้อมูลการเงินเริ่มไหลเข้าระบบได้

- ผังบัญชีเบื้องต้นสำหรับจัดหมวดรายการ
- รายการรับเงินและรายการจ่ายเงินที่เชื่อมกับใบแจ้งหนี้และการรับชำระใน
  [Billing](/docs/modules/billing)
- ข้อมูลภาษีที่จำเป็นต่อการออกเอกสาร
- รายงานการเงินเบื้องต้นสำหรับตรวจสอบความถูกต้องของข้อมูล

## ยังไม่รวมในรอบนี้

ความสามารถต่อไปนี้อยู่ใน requirement ของโมดูลการเงิน แต่ยังไม่เปิดใช้ในรอบปัจจุบัน

- บัญชีแยกประเภทและการบันทึกรายการบัญชีเต็มรูปแบบ
- บัญชีลูกหนี้และบัญชีเจ้าหนี้ พร้อมรายงานอายุหนี้
- ภาษีมูลค่าเพิ่มและภาษีหัก ณ ที่จ่าย พร้อมรายงานภาษี
- งบการเงิน ได้แก่ งบกำไรขาดทุน งบดุล และงบกระแสเงินสด
- การกระทบยอดบัญชีและการจัดการหลายสกุลเงิน
- การควบคุมงบประมาณและการอนุมัติค่าใช้จ่าย
