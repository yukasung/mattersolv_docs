# Billing

โมดูลวางบิลและรับชำระดูแลเส้นทางของเงินตั้งแต่ลูกความตอบรับใบเสนอราคา
ไปจนถึงรับเงินครบและออกใบเสร็จ โดยอ้างอิงเวลาทำงานและค่าใช้จ่ายที่บันทึกไว้ใน
แฟ้มงานกฎหมาย เพื่อให้ยอดที่เรียกเก็บตรวจย้อนกลับได้ว่ามาจากงานใด

ผู้ใช้หลักคือทีมการเงินและบัญชี ทนายผู้รับผิดชอบงาน และผู้บริหารที่อนุมัติ

## Key Capabilities

### จากใบเสนอราคาสู่ใบแจ้งหนี้

- แปลงใบเสนอราคาที่ลูกความตอบรับแล้วเป็นรายการขาย
- ออกใบแจ้งหนี้จากรายการขาย โดยหนึ่งรายการขายออกใบแจ้งหนี้ได้หลายฉบับ
- แบ่งงวดชำระตามเงื่อนไขที่ตกลงไว้
- ออกใบกำกับภาษีและใบเสร็จรับเงิน

### เงินมัดจำ

- ตั้งเงื่อนไขการมัดจำและรับเงินมัดจำจากลูกความ
- แยกเงินมัดจำออกจากรายได้จนกว่าจะมีการใช้จริง
- หักเงินมัดจำออกจากยอดที่ต้องชำระเมื่อออกใบแจ้งหนี้
- คืนเงินมัดจำเมื่อมีการยกเลิก และติดตามสถานะเงินมัดจำ

### รับชำระและติดตาม

- บันทึกการรับชำระและตัดยอดใบแจ้งหนี้ที่เกี่ยวข้อง
- บันทึกการรับเงินได้หลายช่องทางตามที่สำนักงานใช้จริง
- ติดตามยอดค้างชำระและรายการที่ยังชำระไม่ครบ
- บันทึกการจ่ายค่าใช้จ่ายของสำนักงานที่เกี่ยวข้องกับงาน

การเชื่อมต่อผู้ให้บริการรับชำระเงินออนไลน์ เช่น บัตรเครดิตและ PromptPay/QR
ยังไม่ได้เลือกผู้ให้บริการ จึงต้องได้ข้อสรุปก่อนเปิดใช้งานจริง
