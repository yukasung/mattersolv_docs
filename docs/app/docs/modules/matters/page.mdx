# Matters

Matter (แฟ้มงานกฎหมาย) คือหน่วยงานหลักของระบบ ใช้รวมทุกอย่างที่เกี่ยวกับงานหนึ่งเรื่อง
ไว้ด้วยกัน ทั้งลูกความ คู่กรณี ทีมทนาย เอกสาร งานย่อย นัดหมาย เวลาทำงาน
และการวางบิล ทำให้ตอบได้ว่างานหนึ่งเรื่องคืบหน้าถึงไหนและใช้ทรัพยากรไปเท่าใด

ผู้ใช้หลักคือทนายผู้รับผิดชอบ ผู้จัดการคดี และผู้บริหารที่ดูภาพรวม

## Key Capabilities

### เปิดและลงทะเบียนแฟ้มงาน

- บันทึกข้อมูลพื้นฐาน เช่น ชื่อเรื่อง หมายเลขคดี และประเภทคดี
- แนบลูกความ คู่กรณี และบุคคลที่เกี่ยวข้อง
- ระบุทีมทนายผู้รับผิดชอบและบทบาทของแต่ละคนในแฟ้มงาน
- บันทึกสถานะของงาน เช่น อยู่ระหว่างพิจารณา ยื่นฟ้อง ไกล่เกลี่ย หรือปิดงาน
  โดยแยกจากสถานะการวางบิล

### ประเมินก่อนรับงาน

- ตรวจว่ามีแฟ้มงานเดิมเรื่องเดียวกันอยู่แล้วหรือไม่
- ตรวจผลประโยชน์ขัดกันระหว่างลูกความ คู่กรณี และทนายผู้รับผิดชอบ
- ประเมินความเสี่ยงของงานและบันทึกเหตุผลของการรับหรือไม่รับงานไว้เป็นหลักฐาน

### ดำเนินงานและติดตาม

- Timeline แสดงความคืบหน้าของแฟ้มงาน
- บันทึกนัดหมายและกำหนดการที่เชื่อมกับ [Calendar](/docs/modules/calendar)
- มอบหมายงานย่อยผ่าน [Tasks](/docs/modules/tasks)
- แนบเอกสารและสร้างเอกสารจากแม่แบบผ่าน [Documents](/docs/modules/documents)
- แจ้งเตือนอัตโนมัติเมื่อใกล้ถึงกำหนด

### บันทึกเวลาทำงาน

- จับเวลาการทำงานแบบเริ่มและหยุด หรือบันทึกย้อนหลังพร้อมรายละเอียดงาน
- ระบุประเภทของงานที่ทำ และแยกงานที่เรียกเก็บเงินได้ออกจากงานที่เรียกเก็บไม่ได้
- ผูกเวลาที่บันทึกเข้ากับแฟ้มงาน งานย่อย หรือเอกสารที่เกี่ยวข้อง
- ส่งเวลาที่บันทึกให้ผู้มีอำนาจตรวจสอบและอนุมัติก่อนนำไปวางบิล
- ล็อกรายการที่อนุมัติหรือเรียกเก็บเงินไปแล้วไม่ให้แก้ไข
  และแจ้งเตือนเมื่อมีการแก้ไขรายการเวลา

### ปิดแฟ้มงาน

- ตรวจความครบถ้วนของงาน เอกสาร เวลา และยอดเงินก่อนปิด
- ปิดแฟ้มงานแล้วเริ่มนับระยะเวลาจัดเก็บข้อมูลตามที่กำหนด
