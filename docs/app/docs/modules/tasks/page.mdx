# Tasks

โมดูลงานและทีมใช้แตกงานหนึ่งเรื่องออกเป็นงานย่อยที่มีผู้รับผิดชอบและกำหนดส่งชัดเจน
แล้วติดตามความคืบหน้าจนปิดงาน โดยผูกกับแฟ้มงานกฎหมายเพื่อให้เห็นว่างานย่อยแต่ละชิ้น
สนับสนุนงานเรื่องใดอยู่

ผู้ใช้หลักคือทนายความ ทีมงานที่ได้รับมอบหมาย และผู้จัดการที่ดูแลภาระงานของทีม

## Key Capabilities

### สร้างและจัดหมวดงาน

- สร้างงานใหม่พร้อมชื่อ รายละเอียด วันที่เริ่มต้นและสิ้นสุด
- กำหนดประเภทของงาน เช่น งานด้านกฎหมาย งานบริหาร หรืองานการเงิน
- เชื่อมงานกับแฟ้มงานกฎหมายและลูกความที่เกี่ยวข้อง
- แนบไฟล์และเอกสารประกอบงาน

### มอบหมายและติดตาม

- มอบหมายงานให้ทนายหรือลูกทีม โดยระบุผู้รับผิดชอบหลักและผู้ร่วมงาน
- กำหนดระดับความสำคัญของงาน
- ติดตามสถานะงาน เช่น รอเริ่ม กำลังดำเนินการ และเสร็จสิ้น
- แจ้งเตือนผู้เกี่ยวข้องเมื่อมีการอัปเดตงาน

### เวลาและภาระงาน

- จับเวลาการทำงานจากงานย่อยและส่งต่อไปยังการบันทึกเวลาใน
  [Matters](/docs/modules/matters)
- วิเคราะห์ภาระงานของทีมเพื่อดูว่าสมาชิกคนใดมีงานมากเกินไป
- Dashboard แสดงจำนวนงานที่เสร็จสิ้นและงานที่ยังค้าง
