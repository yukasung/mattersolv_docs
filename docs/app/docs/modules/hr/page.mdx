# Human Resources

โมดูลทรัพยากรบุคคลดูแลข้อมูลบุคลากรของสำนักงาน การคำนวณเงินเดือน
และการลาออนไลน์ เพื่อให้งานบุคคลอยู่ในระบบเดียวกับงานกฎหมาย
และส่งข้อมูลต่อให้งานบัญชีได้

ผู้ใช้หลักคือทีม HR และผู้ดูแลระบบของสำนักงาน ส่วนพนักงานเข้าใช้เพื่อยื่นใบลา
และดู payslip ของตนเอง

## Key Capabilities

### เงินเดือน (Payroll)

- คำนวณภาษี ประกันสังคม และกองทุนตามเงื่อนไขของแต่ละคน
- คำนวณ OT เบี้ยขยัน และโบนัส
- ออก payslip แบบออนไลน์ให้พนักงานเข้าดูได้เอง
- ส่งออกข้อมูลและรายงานเพื่อส่งต่อให้งานบัญชี

### การลา (Leave Management)

- ยื่นใบลาและอนุมัติการลาผ่านระบบ
- เก็บประวัติการลาของบุคลากรแต่ละคน

## Boundary

โมดูลนี้ครอบคลุมงานเงินเดือนและการลา ส่วนการบันทึกเวลาทำงานของทนาย
เพื่อนำไปเรียกเก็บเงินจากลูกความอยู่ใน [Matters](/docs/modules/matters)
เพราะเป็นคนละวัตถุประสงค์กัน

การบันทึกเวลาเข้าออกงานและการประเมินผลงานของบุคลากรยังไม่อยู่ในขอบเขตรอบนี้
