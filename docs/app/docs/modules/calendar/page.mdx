# Calendar

โมดูลปฏิทินและตารางนัดหมายรวมกำหนดการของทนายและทีมไว้ที่เดียว
ทั้งวันขึ้นศาล นัดหมายลูกความ กำหนดส่งเอกสาร และการประชุมภายใน
โดยผูกกับแฟ้มงานกฎหมายเพื่อให้เห็นว่ากำหนดการแต่ละรายการเกี่ยวกับงานใด

ผู้ใช้หลักคือทนายความ ทีมงานที่ร่วมแฟ้มงาน และผู้จัดการที่ต้องจัดสรรเวลาของทีม

## Key Capabilities

### สร้างและจัดการนัดหมาย

- สร้างนัดหมายโดยเลือกประเภทงาน เช่น การประชุม การขึ้นศาล หรือการยื่นเอกสาร
- ตั้งนัดหมายที่เกิดซ้ำเป็นประจำ (Recurring Appointments) รายวัน รายสัปดาห์ หรือรายเดือน
- แนบลูกความและแฟ้มงานกฎหมายที่เกี่ยวข้องกับนัดหมาย
- แนบไฟล์และบันทึกสำคัญ เช่น เอกสารประกอบการประชุม

### แจ้งเตือนและติดตาม

- แจ้งเตือนล่วงหน้าผ่านอีเมล LINE หรือ SMS ตามเวลาที่กำหนด
- แจ้งเตือนอัจฉริยะที่สรุปข้อมูลที่ต้องเตรียมก่อนถึงนัดหมาย
- ติดตามว่านัดหมายเกิดขึ้นจริง ถูกเลื่อน หรือถูกยกเลิก

### ปฏิทินส่วนตัวและปฏิทินทีม

- ปฏิทินส่วนตัวของผู้ใช้แต่ละคน
- ปฏิทินทีมที่แสดงตารางของทนายคนอื่นที่เกี่ยวข้องกับแฟ้มงานเดียวกัน
- กำหนดเวลาว่างของทนาย เพื่อลดการนัดหมายทับซ้อน
- บล็อกเวลาสำหรับงานที่ต้องใช้สมาธิ เช่น การเตรียมคดี
  โดยระบบจะเตือนเมื่อมอบหมายงานในช่วงที่ทนายไม่ว่าง แต่ยังยืนยันมอบหมายได้

### เชื่อมกับโมดูลอื่น

- เชื่อมกับ [Matters](/docs/modules/matters) เพื่อดึงกำหนดการของแฟ้มงานมาแสดง
- เชื่อมกับ [Tasks](/docs/modules/tasks) สำหรับกำหนดส่งงาน
- เชื่อมกับปฏิทินภายนอก เช่น Google Calendar และ Outlook Calendar
