# Documents

โมดูลเอกสารดูแล Document (เอกสารทางกฎหมาย) ตั้งแต่สร้างจากแม่แบบ ตรวจทาน อนุมัติ
ลงนาม จนถึงจัดเก็บและค้นหา โดยเน้นลดการพิมพ์ข้อมูลซ้ำด้วยการดึงข้อมูลลูกความ
และแฟ้มงานกฎหมายมาเติมในเอกสารให้อัตโนมัติ

ผู้ใช้หลักคือทนายความที่ร่างเอกสาร ทนายอาวุโสที่ตรวจและอนุมัติ และทีมธุรการ

## Key Capabilities

### สร้างเอกสารอัตโนมัติ

- สร้างเอกสารจาก Document Template (แม่แบบเอกสารทางกฎหมาย) ที่เตรียมไว้
- ระบบเติมข้อมูลจากฐานข้อมูลลูกความหรือแฟ้มงานลงในเอกสารให้
- รองรับข้อความและเงื่อนไขที่เปลี่ยนตามข้อมูลที่กรอก
- กรอกข้อมูลผ่านแบบฟอร์มออนไลน์แล้วให้ระบบสร้างเอกสารพร้อมรันเลขเอกสาร
- ปรับโลโก้และที่อยู่ของสำนักงานบนเอกสารได้

### ฟอร์มเอกสารศาล

- ฟอร์มเอกสารศาลตามรูปแบบของศาลไทย เช่น ใบแต่งทนายความและใบมอบฉันทะ
  โดยเลือกฟอร์มให้สอดคล้องกับศาลที่ยื่นเรื่อง
- ฟอร์มเอกสารทั่วไปของสำนักงาน เช่น หนังสือมอบอำนาจ
  สัญญาจ้างที่ปรึกษาหรือทนายความ และใบเสนอค่าบริการวิชาชีพ
- ข้อมูลศาล เขตอำนาจศาล และประเภท Court Case (คดีศาล) ที่ใช้เลือกฟอร์ม
  ดูแลอยู่ใน [Administration](/docs/modules/administration)

โมดูลนี้ครอบคลุมการจัดทำ ตรวจทาน และส่งออกฟอร์มเอกสารศาล
แต่**ไม่รวมการยื่นเรื่องต่อศาลผ่านระบบ**

### ตรวจทาน อนุมัติ และลงนาม

- ส่งเอกสารให้ผู้มีอำนาจตรวจสอบ แก้ไข และอนุมัติก่อนนำไปใช้
- ติดตามสถานะเอกสารว่าอยู่ขั้นตอนใด
- ลงนามอิเล็กทรอนิกส์ในระบบ และส่งเอกสารให้ลูกความลงนามออนไลน์

### จัดเก็บและค้นหา

- อัปโหลดเอกสารได้หลายประเภท ทั้ง PDF, Word, Excel และรูปภาพ
- จัดหมวดหมู่เอกสารตามประเภทคดี และติดแท็กเพื่อให้ค้นหาง่าย
- เชื่อมเอกสารกับแฟ้มงานกฎหมายและลูกความ
- ค้นหาตามชื่อไฟล์ แท็ก แฟ้มงาน ลูกความ หรือวันที่อัปโหลด

### เวอร์ชันและการควบคุม

- เก็บเวอร์ชันของเอกสารและย้อนกลับไปใช้เวอร์ชันก่อนหน้าได้
- บันทึกว่าใครแก้ไขเอกสารเมื่อใด
- ล็อกไฟล์สำคัญเพื่อป้องกันการแก้ไข
- แชร์เอกสารกับทีมและส่งออกเป็น PDF, Word หรือ Excel
