# Modules

หน้ากลุ่ม Modules ใช้อธิบายความสามารถและขอบเขตการทำงานของระบบ โดยไม่กำหนดราคา
แผน หรือสิทธิ์ของผู้ใช้

## Documentation Boundary

- รายละเอียดว่าระบบทำอะไรอยู่ในหน้า Module แต่ละรายการ
- แผนใดเปิดฟีเจอร์ใดให้ตรวจจาก Feature Comparison
- ผู้ใช้คนใดทำรายการได้ให้ตรวจจาก Roles และ Permissions
- ลำดับการทำงานหลักให้ตรวจจาก [Business Workflow](/docs/workflow)

## Available Module Documents

เรียงตามลำดับงานจริง ตั้งแต่รับลูกความจนถึงงานดูแลระบบ

- [Clients](/docs/modules/clients) — ทะเบียนลูกความ
  และลิงก์ให้ลูกความกรอกข้อมูลเอง
- [Matters](/docs/modules/matters) — แฟ้มงานกฎหมาย การตรวจก่อนรับงาน และเวลาทำงาน
- [Documents](/docs/modules/documents) — เอกสารอัตโนมัติและฟอร์มเอกสารศาล
- [Quotations](/docs/modules/quotations) — ใบเสนอราคาและขอบเขตบริการ
- [Calendar](/docs/modules/calendar) — นัดหมายและตารางของทีม
- [Tasks](/docs/modules/tasks) — งานย่อยและภาระงานของทีม
- [Billing](/docs/modules/billing) — วางบิล เงินมัดจำ และการรับชำระ
- [Finance](/docs/modules/finance) — ข้อมูลตั้งต้นด้านบัญชีและการเงิน
- [Human Resources](/docs/modules/hr) — เงินเดือนและการลาของบุคลากร
- [Reports](/docs/modules/reports) — รายงานและ dashboard ของทุกโมดูล
- [Administration](/docs/modules/administration) — tenant, ผู้ใช้งาน, ข้อมูลกลาง และการแจ้งเตือน
