# Modules

หน้ากลุ่มโมดูลใช้อธิบายความสามารถและขอบเขตการทำงานของระบบ โดยไม่กำหนดราคา
แผน หรือสิทธิ์ของผู้ใช้

## Documentation Boundary

- รายละเอียดว่าระบบทำอะไรอยู่ในหน้าโมดูลแต่ละรายการ
- แผนใดเปิดฟีเจอร์ใดให้ตรวจจากการเปรียบเทียบแผน
- ผู้ใช้คนใดทำรายการได้ให้ตรวจจากบทบาทและสิทธิ์
- ลำดับการทำงานหลักให้ตรวจจาก [เวิร์กโฟลว์ธุรกิจ](/docs/workflow)

## Available Module Documents

เรียงตามลำดับงานจริง ตั้งแต่รับลูกค้าจนถึงงานดูแลระบบ

- [Clients](/docs/modules/clients) — ทะเบียนลูกค้า
  และลิงก์ให้ลูกค้ากรอกข้อมูลเอง
- [Matters](/docs/modules/matters) — แฟ้มงานกฎหมาย การตรวจก่อนรับงาน และเวลาทำงาน
- [Documents](/docs/modules/documents) — เอกสารอัตโนมัติและฟอร์มเอกสารศาล
- [Quotations](/docs/modules/quotations) — ใบเสนอราคาและขอบเขตบริการ
- [Calendar](/docs/modules/calendar) — นัดหมายและตารางของทีม
- [Tasks](/docs/modules/tasks) — งานย่อยและภาระงานของทีม
- [Billing](/docs/modules/billing) — วางบิล เงินมัดจำ และการรับชำระ
- [Finance](/docs/modules/finance) — ข้อมูลตั้งต้นด้านบัญชีและการเงิน
- [Human Resources](/docs/modules/hr) — เงินเดือนและการลาของบุคลากร
- [Reports](/docs/modules/reports) — รายงานและแดชบอร์ดของทุกโมดูล
- [Administration](/docs/modules/administration) — สำนักงาน ผู้ใช้งาน ข้อมูลกลาง และการแจ้งเตือน
