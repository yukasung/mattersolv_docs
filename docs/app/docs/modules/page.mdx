# โมดูล

หน้ากลุ่มโมดูลใช้อธิบายความสามารถและขอบเขตการทำงานของระบบ โดยไม่กำหนดราคา
แผน หรือสิทธิ์ของผู้ใช้

## ขอบเขตเอกสาร

- รายละเอียดว่าระบบทำอะไรอยู่ในหน้าโมดูลแต่ละรายการ
- แผนใดเปิดฟีเจอร์ใดให้ตรวจจากการเปรียบเทียบแผน
- ผู้ใช้คนใดทำรายการได้ให้ตรวจจากบทบาทและสิทธิ์
- ลำดับการทำงานหลักให้ตรวจจาก [เวิร์กโฟลว์ธุรกิจ](/docs/workflow)

## เอกสารโมดูลที่มี

เรียงตามลำดับงานจริง ตั้งแต่รับลูกค้าจนถึงงานดูแลระบบ

- [ลูกค้า](/docs/modules/clients) — ทะเบียนลูกค้า
  และลิงก์ให้ลูกค้ากรอกข้อมูลเอง
- [คดีและงานกฎหมาย](/docs/modules/matters) — แฟ้มงานกฎหมาย การตรวจก่อนรับงาน และเวลาทำงาน
- [เอกสาร](/docs/modules/documents) — เอกสารอัตโนมัติและฟอร์มเอกสารศาล
- [ใบเสนอราคา](/docs/modules/quotations) — ใบเสนอราคาและขอบเขตบริการ
- [ปฏิทินนัดหมาย](/docs/modules/calendar) — นัดหมายและตารางของทีม
- [งาน](/docs/modules/tasks) — งานย่อยและภาระงานของทีม
- [การวางบิล](/docs/modules/billing) — วางบิล เงินมัดจำ และการรับชำระ
- [การเงินและบัญชี](/docs/modules/finance) — ข้อมูลตั้งต้นด้านบัญชีและการเงิน
- [บุคลากร](/docs/modules/hr) — เงินเดือนและการลาของบุคลากร
- [รายงาน](/docs/modules/reports) — รายงานและแดชบอร์ดของทุกโมดูล
- [การดูแลระบบ](/docs/modules/administration) — สำนักงาน ผู้ใช้งาน ข้อมูลกลาง และการแจ้งเตือน
